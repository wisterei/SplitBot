# SplitBot

Telegram-бот для общих расходов в компании друзей: кто сколько заплатил, кто кому должен и как рассчитаться меньшим числом переводов.

## Что умеет

- Добавлять расходы: кто заплатил, сумма, между кем делим, комментарий. Сумму можно ввести примером: `99+322`, `3000/4`, `(1200+800)/3`.
- Показывать балансы и минимальный набор переводов, чтобы всем рассчитаться.
- Отмечать переводы («Оплачено») и отменять их.
- Историю операций с постраничным просмотром, правку и удаление расходов.
- Статистику: сколько потрачено, кто сколько оплатил, на кого сколько пришлось.
- Работать в группе и в личных сообщениях. В личке бот показывает группы, где ты участвуешь, и работает с выбранной, пока её не сменишь (`/groups`).

## Как пользоваться

1. Добавь бота в группу и отправь `/menu`.
2. Каждый участник нажимает «🙋 Я участвую».
3. Дальше всё через кнопки — в группе или в личке с ботом.

## Стек

| Что | Версия |
| --- | --- |
| Python | 3.13 |
| aiogram | 3.30 |
| aiohttp-socks | 0.12 (прокси до Telegram) |
| python-dotenv | 1.2.3 |
| SQLite | встроен в Python |
| Docker Compose | для запуска на сервере |

Весь код — в `bot.py`. Таблицы базы создаются и дополняются автоматически при старте, существующие данные не трогаются.

## Настройки

Файл `.env` рядом с `bot.py` (в git не попадает):

```ini
BOT_TOKEN=123456:ABC...
# Необязательно:
# PROXY_URL=socks5://127.0.0.1:10808   (по умолчанию; пустое значение — без прокси)
# DATABASE_PATH=splitwise.db           (по умолчанию)
```

## Локальный запуск (Windows)

```powershell
git clone https://github.com/wisterei/SplitBot.git
cd SplitBot
py -3.13 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python.exe bot.py
```

Для тестов используй отдельного бота: один токен нельзя опрашивать с двух машин одновременно.

## Запуск на сервере (Linux + Docker)

Первый запуск:

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Склонируй репозиторий:

   ```bash
   git clone https://github.com/wisterei/SplitBot.git ~/SplitBot
   cd ~/SplitBot
   ```

3. Создай `.env` и впиши в него `BOT_TOKEN=<токен>`:

   ```bash
   nano .env
   ```

4. Создай папку для базы и запусти бота:

   ```bash
   mkdir -p data
   docker compose up -d --build
   ```

5. Проверь логи — должно появиться «Бот запущен!»:

   ```bash
   docker compose logs -f --tail=50
   ```

6. Добавь бота в группу, отправь `/menu` и нажми «🙋 Я участвую».

Контейнер работает с `network_mode: host`, чтобы видеть прокси (xray) на `127.0.0.1` хоста. База лежит в `./data/splitwise.db` и переживает пересборку.

Обновление:

```bash
cd ~/SplitBot && git pull && docker compose up -d --build
```

Полезное:

```bash
docker compose logs -f --tail=100   # логи
docker compose restart              # перезапуск
```

Перед рискованным обновлением сделай копию базы:

```bash
cp data/splitwise.db data/splitwise_backup_$(date +%F).db
```
